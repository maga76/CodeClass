# CodeClass

Программа для уроков программирования: учитель создаёт задания на Python, C++ и HTML,
ученики решают их, CodeClass сам проверяет код и ставит балл от 1 до 10.

## Установка

Запустите `desktop\installer\CodeClass-Setup-1.0.0.exe` → «Далее» → «Установить».
Права администратора не нужны. Тот же установщик ставится и учителю, и ученикам.

## Как пользоваться в классе

1. **Учитель** запускает CodeClass и выбирает «Я учитель». Сервер запускается на его компьютере сам.
   Если Windows спросит про брандмауэр — нажать «Разрешить доступ».
2. Учитель регистрируется, создаёт класс и задания. На главной странице виден
   **адрес для учеников**, например `http://192.168.1.10:8002`, а на странице класса — **код класса**.
3. **Ученик** запускает CodeClass, выбирает «Я ученик», вводит адрес учителя,
   регистрируется и вступает в класс по коду. Вместо программы можно открыть адрес в любом браузере.
4. Во время урока программа учителя должна быть открыта. Компьютеры — в одной сети (Wi-Fi или кабель).
   Интернет не нужен.

Сменить режим или адрес сервера: меню **Настройки** в окне программы.

## Попробовать сразу (демо)

На странице входа есть блок «Демо-доступ» — кнопки входа одним нажатием:

| Кто | Логин | Пароль |
|---|---|---|
| Учитель | `teacher` | `teacher123` |
| Ученик | `student` | `student123` |

Там уже есть класс «Информатика — 9 «А»» (код `DEMO9A`) с 12 заданиями: 8 на Python, 2 на C++, 2 на HTML.
У учеников Мадины и Тимура есть решения, ученик `student` — чистый, чтобы решать самому.

- Загрузить демо: `python manage.py load_demo`
- **Удалить демо перед настоящими уроками**: `python manage.py load_demo --remove`
  (пароли демо-аккаунтов видны всем на странице входа)

На новом компьютере учитель может нажать «Создать пример класса» в кабинете — появится класс
с теми же 12 заданиями, без демо-учеников.

## Что умеет

- **Учитель**: классы с кодом для вступления, задания на Python / C++ (тесты «ввод → вывод») и HTML
  (правила по CSS-селекторам), скрытые тесты, дедлайны, журнал, просмотр кода учеников, своя оценка
  с комментарием, выгрузка журнала в Excel, сброс пароля ученику, исключение из класса.
- **Ученик**: редактор как в VS Code, живой просмотр HTML, запуск на своих данных, результат по каждому
  тесту, история попыток, смена пароля.

## Где данные

`%APPDATA%\CodeClass` — база (`db.sqlite3`), настройки и журнал ошибок (`codeclass.log`).
При удалении программы данные сохраняются. Для резервной копии достаточно скопировать `db.sqlite3`.

## Ограничения

- **C++** проверяется, только если на компьютере учителя установлен компилятор `g++`
  (`winget install BrechtSanders.WinLibs.POSIX.UCRT`; CodeClass находит его сам, даже без перезагрузки).
  Без него ученик увидит «компилятор не установлен».
- **Smart App Control** (Windows 11) блокирует неподписанные программы: сам `CodeClass.exe` и каждую
  скомпилированную программу на C++. На таком компьютере запускайте CodeClass ярлыком `CodeClass.lnk`
  из папки проекта, а C++ заработает только после выключения Smart App Control (или с подписанной сборкой).
  Ученик в этом случае видит понятное сообщение, а не ошибку.
- В режиме «сервер на компьютере учителя» код учеников запускается без изоляции (с ограничением времени).
  Для школьного класса этого достаточно; для открытого сайта в интернете — см. ниже.

## Для разработчика

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt -r desktop\requirements.txt
.\.venv\Scripts\python manage.py migrate
.\.venv\Scripts\python manage.py runserver 8001     # сайт: http://127.0.0.1:8001/
.\.venv\Scripts\python manage.py test               # тесты
.\.venv\Scripts\python desktop\app.py               # программа из исходников
powershell -ExecutionPolicy Bypass -File desktop\build_exe.ps1   # сборка .exe и установщика
```

Для сборки установщика нужен Inno Setup: `winget install JRSoftware.InnoSetup`.

### Сайт в интернете (сервер Ubuntu, без Docker)

```bash
sudo bash deploy/setup.sh codeclass.example.com
sudo bash /srv/codeclass/deploy/manage.sh createsuperuser
```

Ставит Python, g++, bubblewrap (изоляция кода учеников: без сети и без доступа к файлам сайта) и Caddy
(HTTPS), настраивает автозапуск. В программе ученики выбирают «Я ученик» и вводят `https://ваш-домен`.

### Структура

- `accounts/` — пользователи с ролями, регистрация, вход, смена пароля
- `classroom/` — классы, задания, тесты, решения, оценки, журнал
- `classroom/judge.py`, `classroom/sandbox.py` — проверка решений и запуск кода с ограничениями
- `desktop/` — программа для Windows (pywebview + waitress + PyInstaller) и установщик (Inno Setup)
- `static/vendor/` — редактор Monaco и шрифты (лежат в проекте, чтобы всё работало без интернета)
- `deploy/` — установка на сервер Linux
